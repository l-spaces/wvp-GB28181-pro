# PRD：大屏接入 WVP 后端真实数据

## 背景

`visual/` 下已按 bigscreen-mockup.html 原型实现 Vue3 + TS 大屏（设备树 / 视频墙 / 云台控制 / 分屏模式 / 设备状态 / 告警信息 / 快捷操作），当前全部使用 `src/data/mock.ts` 静态数据。用户已在 `visual/.env` 配置了 `VITE_API_BASE_URL` 与 `VITE_API_KEY`，要求把页面展示的数据替换为 WVP 后端真实接口数据。

## 范围

基于**现有页面现有展示的功能**填充数据，不新增页面/交互：

| 区块 | 现状 | 目标 |
|---|---|---|
| 左侧设备树 | mock 树（全部设备/公司大楼/1/2号楼/园区） | WVP 设备/通道接口的真实层级与在线状态 |
| 中部视频墙 | 9 张 base64 快照图片 | play/start 返回的流地址（能力允许时用 WebRTC/FLV 播放，否则降级显示快照/占位） |
| 右侧云台控制 | 仅 toast 提示 | 调用 front-end/ptz 接口真实下发云台指令 |
| 底部设备状态 | 静态数字（16/12/3/1，球机5 枪机11 NVR0） | 真实统计（在线/离线/总数） |
| 底部告警信息 | 5 条静态告警 | 真实告警接口数据（若后端无事件类告警，如实降级说明） |
| 顶栏/快捷操作 | 静态文本与 toast | 不接入后端，维持现状 |

## 认证与配置

- 沿用 `visual/.env`：`VITE_API_BASE_URL`、`VITE_API_KEY`
- 请求头 `api-key: <key>`（demo/src/api/wvp.ts 已验证的方案）
- 配置读取统一走 `src/config/env.ts`

## 验收标准

1. `pnpm dev` 打开页面，设备树展示后端真实设备/通道（名称、在线状态）
2. 点击视频卡触发播放请求，拿到流地址并在卡片内播放（或降级显示明确提示）
3. 云台方向/变倍/聚焦按钮向后端真实下发指令（成功/失败有 toast 反馈）
4. 设备状态统计来自真实接口
5. 告警列表来自真实接口（若后端无此类数据，保留静态展示并在 README 说明）
6. `pnpm build` 通过（vue-tsc 严格类型检查）
7. 后端不可达时页面不白屏，各区块显示错误占位

## 非目标

- 不改后端 Java 代码
- 不做登录页/用户管理（用 API key 直连）
- 不做录像回放、语音对讲等快捷操作的真实实现
- 不重构现有组件结构（保持 8 组件 + composable 结构）
